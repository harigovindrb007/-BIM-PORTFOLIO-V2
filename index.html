⚡ BIM Automation & Python Scripting

Batch Sheet Revision Date Manager

During formal project submissions and tender resubmissions, title block revision dates across dozens or hundreds of sheets frequently need to be updated simultaneously. Manually opening and editing each sheet title block in Revit is repetitive, time-consuming, and prone to human error.

To solve this bottleneck, I developed a custom selection-based Dynamo script powered by an internal Python (IronPython 2 / RevitAPI) node. The script directly interfaces with Revit's active document session, captures user-selected sheets in the Project Browser, validates date inputs, supports a non-destructive preview mode, and safely commits batch parameter updates through TransactionManager with a single click.
